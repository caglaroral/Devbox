    Settings

    API keys / environment variables

    Passed to sessions as environment variables (tmux set-environment -g and -e on every window). Values are kept in the secret store and never shown again. Running sessions see a new value after a restart.

    Team board access

    Sessions get DEVBOX_URL and DEVBOX_TOKEN automatically; the devbox-msg tool uses them. To install it on a machine:

    tmux

    For sessions on remote hosts to post to the board, this URL must be reachable from those hosts (DEVBOX_PUBLIC_URL).

    Secret store
    Depo

    API keys, SSH private keys and stored host passwords live here; private keys are only written to a temporary file in RAM (tmpfs) while connecting.

    Event log

    Terminal connects/disconnects (who closed it, after how long, from which device), host reachability, sessions, uploads, logins and console restarts.
